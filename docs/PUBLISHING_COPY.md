## Laravel Easy Dev v3.1.1 - Documentation Refresh

This release refreshes Laravel Easy Dev documentation and package metadata for Laravel project use.

Laravel Easy Dev helps generate production-style Laravel feature structure from one Artisan command.

### Highlights

- Cleaner README positioning and quick start
- Dedicated AI guide for Codex, Cursor, Claude, and ChatGPT
- Community links for Telegram, GitHub Discussions, and GitHub Issues
- Publish-ready command reference and docs index
- CRUD generation for web and API
- API controllers, resources, requests, and routes
- Optional Repository and Service layers
- Policies, DTOs, observers, filters, and enums
- Feature and unit test generation
- OpenAPI / Swagger generation
- Clean Architecture and DDD-style module support
- Vue, React, Inertia, and Livewire starter stubs
- AI-friendly JSON commands for project context and analysis
- Better stub publishing and customization
- Laravel 9, 10, 11, 12, and 13 support
- GitHub Actions CI compatibility checks

### Install

```bash
composer require anas/easy-dev:^3.1 --dev
```

### Example

```bash
php artisan easy-dev:crud Product --api --with-repository --with-service --tests --swagger
```

Feedback is welcome.
```
